# 论文写作路线图

更新日期：2026-05-27

## 论文定位

**标题方向**：Systematic Benchmarking of Machine Learning Models for Multi-Pesticide Screening via SERS: Preprocessing Effects, Model Selection, and Chemical Interpretability

**核心贡献**：
1. 13模型×6预处理的系统benchmark，揭示预处理×模型交互效应（RF/ExtraTrees在SNV+SG下最优且最稳定）
2. TreeSHAP峰簇分析证明模型决策基于真实化学振动模式而非噪声
3. SHAP-guided spectral region selection证明模型性能可在仅保留化学可解释区域时维持（actionable interpretability）
4. 土壤基质筛查可行性验证（soil-only CV），证明方法在复杂基质中的适用性

**目标期刊**：Spectrochimica Acta Part A (IF 4.1) 或 Chemometrics & ILS (IF 3.9)，均为 Q2

## 叙事弧线

1. 数据质量表征 → 支持数据质量与任务难点讨论
2. 13模型×6预处理 benchmark → 建立模型 landscape
3. Composition-constrained spectral mixing → 以消融验证其任务依赖贡献
4. 模型选择 → ExtraTrees/p1 作为 primary practical model，RamanNet-Lite 作为 DL-family comparator
5. Peak-cluster SHAP → 模型学到的波数对应真实化学信息
6. SHAP-guided spectral region selection → 从解释到行动：仅保留化学区域性能不降
7. 土壤筛查可行性 → soil-only CV 证明方法在复杂基质中可用
8. Discussion → 竞争吸附 + G2瓶颈 + 化学可解释性闭环

## 写作术语规范

**允许使用**：
- conventional spectrum-level validation
- within-dataset screening benchmark
- folder-level transfer stress test
- composition-constrained spectral mixing
- semi-quantitative MG concentration grading
- soil-matrix screening feasibility
- same-matrix CV

**禁止使用**（除非有新证据）：
- random CV = external validation
- leakage-free generalization
- 首次提出 Beer-Lambert augmentation
- SHAP 单独证明竞争吸附
- 17/20 peak matching
- MG 精确定量
- optimized/best-achievable model（除非未来补 nested tuning 证据）
- RamanNet-Lite star model / proposed main model

## 2026-05-24 写作路线更新

新增证据已经改变 §3.3 和 §3.4 的写法：

- §3.3 增强消融可以写，但必须写成“task-dependent benefit”。最强证据是 G3/MBA grade：p1 下 1D-CNN 从 0.167 提升到 0.745，1D-ResNet 从 0.223 提升到 0.779，KAN-CNN 从 0.166 提升到 0.710，Spectrum-KAN 从 0.614 提升到 0.891。
- G2/MG grade 不能写成被增强“解决”。p1 下 Spectrum-KAN 仅从 0.467 到 0.480；1D-ResNet 基本持平；1D-CNN/KAN-CNN 有中等提升。
- RamanNet-Lite 完整 benchmark 已追加到 13 模型矩阵：整体均值 0.877，为当前最强 DL-family 模型；p1 下六任务为 P1 0.961、P2 0.947、P3 0.953、G1 0.998、G2 0.767、G3 0.910。它支持作为 DL-family comparator，但不改变 classical ML 仍为准确率主结论。
- KAN 的论文角色应是 benchmark/reference 和 task-dependence 讨论对象，而不是“新模型主角”。它在 G3 很强，但 G2 明显失配，这个反差比硬救 KAN 更有说服力。
- TabNet/Mamba 暂时不写成核心路线，只保留为 future/backup candidate，除非后续审稿或导师明确要求补充 DL 架构探索。

## 2026-05-25 路线锁定

- 正式 Optuna 从主线移除。论文不写成模型特异性超参优化文章，而写成 standardized benchmark + task-dependent augmentation + chemical interpretability + soil-matrix screening feasibility。
- §3.4 改为”Model selection under fixed reproducible configurations”。ExtraTrees/p1 是后续解释和土壤筛查的 primary practical model；RamanNet-Lite 是 strongest DL-family representative，不是第二个明星模型。
- ExtraTrees 必须描述为项目固定 recipe，不写 sklearn default。当前代码配置为 `n_estimators=400`, `min_samples_leaf=2`, `max_features='sqrt'`, `class_weight='balanced'`。
- 可选的 ExtraTrees robustness check 只放 SI，不叫 Optuna，不用来重选最终成绩。
- 下一步必须补的证据是 SHAP 峰表更新重跑匹配 和 soil-only 5-fold CV；这两项比继续调参更直接支撑分析化学审稿点。
