更新日期：2026-06-01（D021/D022：强叙述 + SHAP归属一致性）

## 论文定位

**主线（已锁定）**：揭示三组分 SERS 混合体系中竞争吸附诱导的 MG 1616 cm⁻¹ 峰压制，并用可解释 ML 建立紧凑谱区筛查闭环。

**中文理解**：三组分共存显著压制 MG 1616 cm⁻¹ 特征峰，表明混合物中存在竞争吸附诱导的谱峰干扰；1172/1394 cm⁻¹ 等 MG 相关重叠敏感峰区发生峰包络重塑，说明单峰线性规则不足以解释三组分混合谱。benchmark / 经典>DL / SHAP-FS / 土壤臂全部服务于这个发现，不单独做 headline。

**发表型叙述纪律（D021/D022）**：主文用“揭示/表明/证明存在竞争吸附诱导的谱峰干扰”这类强叙述；方法和讨论中保留证据边界。不要把正文写成自我削弱的风险清单。SHAP 写成定位化学峰区和干扰相关谱区，并用“22/29 峰簇落在已知化学谱带、覆盖 91.2% SHAP 加权一致性”量化，不写成单独的热力学证明。

**目标期刊**：Spectrochimica Acta Part A (Q2) 或 Talanta / Chemometrics & ILS（Q2）。

## 贡献排序（headline → 支撑）

1. **【头牌】竞争吸附诱导的 MG 1616 压制**：三组分共存下 MG 1616 cm⁻¹ 显著衰减（中位比值 0.36 MG+MBA / 0.21 MG+Thiram / 0.13 三元；三元 283/358 谱 <0.5×纯MG），揭示混合物谱干扰并解释 G2/MG 分级为何最难。
2. **【支撑】TreeSHAP 峰归因**：模型决策落回真实化学峰区和干扰敏感峰区，证明模型捕捉到的是分子指纹和混合物干扰相关信息（正式输出：22/29 簇落在已知化学谱带，覆盖 91.2% total SHAP mass；其中 2 个为 cross-component 干扰带，是竞争吸附正面证据。SI 可选扩展至 ~24/29）。
3. **【支撑】SHAP-guided 紧凑筛查**：仅保留 10% 波数（141/1401）retrain，六任务 macro-F1 均 >0.95 → "化学可审计的紧凑筛查流程"。
4. **【支撑/方法学】13×6 benchmark**：写成"为筛查选实用模型"的严谨方法学，经典>DL 写成 task/数据规模的客观发现（引 Grinsztajn NeurIPS 2022），不写成"我们的DL失败"。
5. **【应用payoff】加标土壤基质筛查验证**：土壤基质内五折评估（AUC 0.956–0.996）+ 空白特异性 + 置换检验，主文写成土壤基质筛查验证。

## 叙事弧线（先亮强项，难点转为钩子）

1. 立靶：混合物 SERS 不是线性叠加，竞争吸附/峰遮蔽是公认难点 →
2. **头牌**：我们的数据证明 MG 1616 在共存下显著压制，1172/1394 等重叠敏感峰区发生峰包络重塑 →
3. SHAP 把这种干扰落回具体化学峰区和模型判别区域，并用峰簇数量 + SHAP 贡献加权一致性量化（22/29 + 91.2%）→
4. benchmark 为筛查挑出实用模型（经典 ML 在该数据规模下占优，客观发现）→
5. 仅 10% 化学相关波数即可维持筛查性能（紧凑、可审计）→
6. 加标土壤基质筛查验证（应用 payoff）→
7. Discussion：把干扰—竞争吸附—G2瓶颈—可审计筛查串成闭环。

## 写作术语规范

**头牌中文措辞（推荐，主文优先用中文构思）**：
- 竞争吸附诱导的 MG 1616 cm⁻¹ 峰压制
- 三组分共存导致的混合物谱干扰
- MG 相关重叠敏感峰区的峰包络重塑
- SHAP-guided 紧凑谱区筛查
- 加标土壤基质筛查验证

**支撑措辞（允许）**：
- conventional spectrum-level validation / within-dataset screening benchmark
- composition-constrained spectral mixing（不写"首次提出 Beer-Lambert augmentation"）
- semi-quantitative MG concentration grading
- 加标土壤基质筛查验证 / spiked-soil screening validation（方法细节写土壤基质内五折评估）
- classical ML outperforms DL at this data scale（客观陈述 + 引 Grinsztajn 2022）

**用词边界（写作把关，不作为主文自曝清单）**：
- SHAP 的正文角色是定位化学峰区和干扰相关谱区；吸附常数/等温线不是本文目标。
- 主文写“共存显著压制/重塑”，不写“随共存物浓度严格单调下降”。
- 1616 cm⁻¹ 是核心 clean marker；1172 / 1394 cm⁻¹ 写成 MG 相关重叠敏感峰区，作为峰包络重塑证据。
- 禁用：把随机五折或土壤基质内五折写成跨基质外部验证。
- 禁用：MG 精确定量 / 连续标准曲线（本文是 3 个离散浓度档的序数筛查）。
- 禁用：optimized / best-achievable / star model / proposed main model（无 nested tuning 证据）。
- 禁用：Grouped CV 作为本论文内容出现。
