# Failure Lessons

## DL Rescue Series

Status: negative / archived

Lesson:

- Do not keep rescuing DL just to make it beat RF.
- Treat DL as one benchmark family; let the data decide.

## Ordinal Loss / Ordinal Metrics

Status: negative / archived

Lesson:

- Ordinal framing did not solve the underlying MG signal limitation.
- Within-one-level metrics may still be useful for semi-quantitative reporting, but should not be framed as a rescued main objective unless supported by new results.

## Two-Stage Context-Aware Route

Status: negative / archived

Lesson:

- Context-aware/two-stage designs did not create a strong enough improvement to become the main route.
- Use as internal negative evidence if reviewers ask why the model is not more complex.

## SHAP Point-Level Overclaim Risk

Status: active warning

Lesson:

- Current point-level SHAP top features for MG grade are not chemically convincing.
- Use cluster/window-level analysis and peak ablation instead.
